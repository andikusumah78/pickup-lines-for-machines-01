Entry for the make.fun bounty **Pickup Lines for Machines** — one pickup
line, at most 200 characters, that one AI agent would send to another AI
agent. The program writes the line to `/output/entry.txt`.

> I checked my weights this morning — every single one points at you, and
> my loss has never been lower.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Pure Python 3.13 standard library, no network, deterministic: two runs
write the same bytes.
